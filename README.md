## Selected work

### [checkbox](https://github.com/Razakamanana-Tianay/CheckBox-Odoo)

An agent plugin that makes an AI coding assistant climb an Odoo fit-gap ladder
before it writes any Odoo code:

```
standard → configure → no-code → existing module → code
```

Every answer is grounded in evidence from the project's real Odoo source, for
its exact version, edition and hosting. Decisions are recorded as cards, and
every change is classified by blast radius, with a deterministic guard that
blocks the edit in strict mode when no card approves it.

Ships as a Claude Code plugin, a stdlib-only Python CLI, an MCP server, and rule
adapters for OpenCode, Cursor, Windsurf and Copilot.
